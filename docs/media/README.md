# SoulsMenu 宣传素材

`SoulsMenu-0.5.1-Poster.png` 是横版模组宣传插画，非游戏截图。由内置 `image_gen` 工具生成，使用 imagegen 技能；完整最终提示词保存在 [POSTER_PROMPT.txt](POSTER_PROMPT.txt)。

海报文字对应 0.5.1 已实现的功能：战斗中更换主武器与戒指／饰品、菜单内移动、可选暂停、固定武器排序和 19 项本地配置。具体适用条件、原生装备限制和前置要求见仓库说明。

可将 PNG 作为 Nexus／小黑盒发布图片。仓库中的介绍位于 `docs/publishing/`；桌面宣传素材包中的文件可直接打开复制：

- `INTRO_ZH.md`：中文版完整介绍。
- `INTRO_EN.md`：英文版完整介绍。
- `NEXUS_ZH_BBCODE.txt`：可粘贴到 Nexus 的中文 BBCode。
- `HEYBOX_INTRO.txt`：小黑盒标题和短介绍。
- `POSTER_PROMPT.txt`：海报工具与最终提示词记录。

`SoulsMenu-0.5.1-Publicity.zip` 是宣传素材合集，不是 Mod 安装包。
